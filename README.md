# Build-a-Complete-Medical-Chatbot-with-LLMs-LangChain-Pinecone---Flask

# How to run?
### STEPS:

clone the repository

```bash
git clonehttps://github.com/mrunalthokal/Build-a-Complete-Medical-Chatbot-with-LLMs-LangChain-Pinecone---Flask.git
```

# STEP 01- create a conda environment after opening the repository

```bash
conda create -n medibot python=3.13.9 -y
```

```bash
conda activate medibot
```

### STEP 02- install the requirements

```bash 
pip install -r requirements.txt
```
